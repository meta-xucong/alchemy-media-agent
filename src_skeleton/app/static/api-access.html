接下来怎么用？

API：给脚本或自动化程序使用，可以创建项目、生成图片、查询状态和下载结果。

示例会提交一次生图任务，运行后按账户原有规则计费。只想让 Codex 使用，请选择 MCP。

MCP：让已安装的 Alchemy MCP 插件调用你的账户。

复制的 MCP 配置不包含安装命令；尚未安装插件时，请先完成 MCP 安装。

停用这把密钥？

使用它的工具将无法发起新请求。已有任务不会被删除，停用后不能恢复。
