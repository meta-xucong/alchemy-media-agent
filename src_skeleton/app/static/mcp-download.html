02 / 配置

安装只需几分钟

  1. 下载并解压 ZIP 到一个固定目录，例如 %USERPROFILE%\AlchemyMCP。
  2. 登录 Alchemy，在 API 与 MCP 页面创建 API 密钥。密钥只显示一次，请自行保存。
  3. 在 Codex 的 Settings → MCP Servers → Add server 中添加本地 STDIO 服务。命令设为 Python 可执行文件；参数为 -m 和 alchemy_api_mcp.server；工作目录设为解压目录。
  4. 添加环境变量 ALCHEMY_PRODUCT_API_BASE_URL=https://alchemy.aiself.vip 和 ALCHEMY_PRODUCT_SESSION_TOKEN=你的 API 密钥，保存后重启 Codex。
  5. 确认工具列表出现 alchemy_list_capabilities，即可查看此密钥可用的 API 范围。

API 密钥不要贴进聊天或 MCP 工具参数。可以在创建密钥时选有效期；生图工具会按账户原有规则计费。

此下载包提供账户 API 的 MCP 接口，不包含原有本地 Native ImageGen / handoff 工具。
