## 已实现

1. V1 受控图片写入前持久化 ID/owner 预约；规范 Output 匹配后发布。原图、列表、缩略图与分享使用一致的权限判定；删除重试权限不充当读取权限。详见 `../publication-security.md`。
2. V1/Lab 派生 schema VERSION 2；普通请求不再全量建库或导入。显式准备命令要求磁盘余量下限，旧版本、未准备或超出增量预算时返回维护要求。V2 同样提供显式准备及只读就绪门禁。
3. 同 ID 来源按索引流式解析，保留完整 owner 冲突判断；共享任务级 payload 保存一份。没有按来源条数截断授权证据。
4. 桌面/移动历史与收藏使用可回访的 72 条窗口，Hero 最多 24 条；服务端收藏过滤分页，释放淘汰图片 Blob URL。V3 逻辑未改。
5. 补充受控冷准备、磁盘门禁、失败恢复、资源模型和独立复审记录。

## 复审状态与仍然存在的边界

独立审查发现的问题已实施防御性修正并运行普通回归，但审查服务中断，最终冻结代码未取得独立安全 PASS。详见 `followup-independent-review.md`；不可将实现者自检冒充独立终审。

权威记录、发布预约及磁盘总量仍随历史增长，本轮没有擅自删除/过期业务数据。收藏精确交集计数 O(F)、深 offset、异常大单条 JSON、不可抢占 SQLite 语句、既有数据库空闲页、外部文件变更和已下载的旧公开副本均有边界。72 条是条目数上限，不是任意 payload 的字节上限；测试窗口探针不等于完整浏览器业务验收。
