# Codex 的 V2 与 LAB 可视化工作台

## 目标与边界

通过 Alchemy 的 `/codex-workbench` 打开轻量工作台。V2 看到真实案例缩略图并任选一个，LAB 看到固定的风格示意并可多选。用户在同一个浏览器标签与 Codex 会话中编辑同一份草稿，明确点生成后才调用既有 API。任务结束自动展示预览和可下载原图，Codex 的媒体回传工具读取同一个输出。

工作台复用同源登录会话，独立页面与静态资源。首版提供需求、案例/风格、画幅和数量，LAB 由所选风格数和每种张数得出总张数。样张不覆盖的 LAB 风格仍可用文字查找，并明确标记暂无样张。既有 API 权限、任务执行、审核、计费和 Bridge 保持原有入口与规则。

## 同一份草稿

- 草稿权威在当前页内。网页点击案例或风格与 WebMCP 更新调用同一个状态更新函数。候选项用后端 ID 传递，展示顺序不作稳定标识。
- 网页主入口已登录时走现有会话；无登录态时由现有 Alchemy 登录入口处理。API key 不进入网页工具参数、页面链接或响应。
- WebMCP 只提供读取当前草稿、查找候选、修改草稿和读取原任务结果。用户从工作台按钮提交，Codex 的选项修改不能触发生图。
- 不要求可交互的会话内 iframe。桌面工作台依赖内置浏览器 Site tools，普通浏览器仍可手动操作。

## 目录与交付

| 场景 | 既有权威 | 工作台行为 |
|---|---|---|
| V2 目录 | `/api/v2/templates/page`、`/api/v2/prompt-cases/search` | 读一页、缩略图惰性加载、按真实案例 ID 选定 |
| LAB 目录 | `/api/lab/rare-style-explorer/styles` | 用当前有效风格 ID 对应示意，分页展示与关键词过滤 |
| V2 任务 | `POST /api/v2/creative/runs/async`、`GET /api/v2/creative/runs/{run_id}` | 保留提交回执和实际案例 ID，预览由已有 history preview 提供，原图走已有 download |
| LAB 任务 | `POST /api/lab/rare-style-explorer/sessions`、随后按 session ID 查询 | 根据原任务 board 的交付记录展示，每张保留实际风格和原图身份 |

首次只发送一次创建请求。V2 丢回执时允许明确使用同一请求内容和原幂等键找回任务。LAB 无通用创建回执恢复时，未知结果交由原有历史核对，不自动补发创建。收到任务 ID 后轮询只读；预览失败显示原图入口和重读控件，重读不改变任务。

独立 MCP 根据产品和输出身份读取受保护媒体。预览返回原生图片块。原图可返回内嵌资源，或在安装时设置本机输出目录，把原样文件和绝对路径交给 Codex 附在回复中。页面自带同一输出的下载入口。会话回传由正在跟踪任务的 Codex 发起，网页不主动创建或唤醒会话。无需发布图片或在地址中携带凭证。

## 实施前审计

截至基线 `7c9c7450`，唯一 main 与 GitHub 一致。现有 V2 目录已支持游标和预览，输出预览与原图受账号权限控制。现有 LAB 接口会返回当前风格库（线上读到 620 项），风格模型无缩略图字段；首批样张对应线上 M001–M003，并非用旧内置 ID。LAB Session 原有资源地址在 `/v1/`，仅有 LAB 权限的密钥无法走该地址。新增两个按原输出身份读取的 LAB 路由，沿用原归属校验及文件解析，仅允许 LAB 的输出。V2 原图读取增加显式直返选项，让 MCP 可以避免将授权头转发给存储站点。现有独立 MCP 输出只有文本 JSON，没有媒体回传类型，因此会话显示和附件需要分别验收。

## 验收

1. 用桌面内置浏览器打开工作台。V2 点可见缩略图，LAB 点能看清风格的示意图。确认后台记录对应案例或风格 ID。
2. 对两个版本分别执行网页点选 → 通过已注册站点工具读取，及站点工具改画幅/数量 → 网页立刻显示，检验使用的是同一个状态。
3. 分别从页面提交一张，跟踪原任务。确认页面自动收到成图及审核，视觉问题不隐藏图片；原图下载点读原输出。
4. 在真实桌面会话核对可见预览与原图附件。用原输出字节校验原图附件，没有支持时如实记为未通过。测试覆盖读失败、任务未知、错误报告与参数边界。

## 2026-11-29 真实生图验收

- 使用候选工作台及独立 MCP，桌面内置浏览器通过仅监听本机的验收入口连接 Alchemy 现网。V2 只提交 1 张，实际采用 Matcha Granola Ad Poster，审核通过，显示的预览为 1024 × 1280。LAB 只提交 1 张，实际采用氧化铜绿锈 M002，预览为 1024 × 1024。两边均在原页面自动显示预览，无需刷新。
- 会话跟踪原任务输出，用候选 MCP 取得预览和原图文件，两张 PNG 分别为 2,893,255 与 2,041,393 字节。复验沿用同一输出，文件摘要一致。V2 还与线上原图接口独立计算的摘要一致。
- 初次回传遇到临时读取失败。MCP 对可重试的网关或传输错误最多继续读取一次；有长度头时不把截断文件交付。认证错误、找不到原图以及重定向不会重试。新增及现有媒体回归共 7 项通过。
- 此验收走实际账户 API，LAB 只在验收入口映射到现网已有的原图地址。新 LAB 专用路由单独通过后端归属回归。该阶段验收不代表候选代码在 VPS 已启用。
