# DOC321 - Output-scoped real-pixel review authority

## Scope and correction model
This is a shared V3 foundation repair, not a new E-Commerce recipe.
The CELISIA product-poster incident is a regression fixture, never a runtime branch.
Baseline: main 3e16d43a; existing records and media remain append-only.

Observed defects in the baseline:
1. Product API clears every eligible output when any inspection is manual or failed.
2. E34 public compression drops output IDs and final-delivery evidence needed by Project.
3. Quality classification treats metadata-only fail statuses as proven pixel failures.
4. Enforced Human Realism defaults to a whole person when the frozen task contains only hands.
5. Human scope is lost again in Brain/finalizer projections; shadow prompts omit brand metadata.
6. Legacy metadata scoring can trigger renderer retries and reject warnings before pixel review.

Authority and compatibility:
- The retained post_generation_review_package is the sole post-generation quality authority.
- Each output needs its own verified pixel pass/warning and applicable certification.
- Incomplete/malformed receipt boundaries remain non-certifying; no inferred pass.
- A manual/missing-face/failing sibling does not withhold independently certified outputs.
- Explicit existing batch contracts remain enforced by their owning scenario layer.
- Metadata preflight and mock scores never certify or reject real pixels.
- Frozen semantic human scope, not arbitrary request/provider metadata, controls face review.
- Pure product: no human/identity obligation. Hands only: anatomy/material/contact, not faces.
- Signed Brain prompts remain immutable; brand context must reach the Brain before sign-off.
- Provider/Brain failures are transport failures, not visual-quality failures.

Acceptance: failing regressions first; focused and adjacent suites; local real CELISIA-like
render and prompt/projection evidence; GitHub push; data-preserving VPS release; real VPS
case and UI evidence; compare local/origin/runtime versions. No phase is total acceptance.

## Continuation implementation - 2026-09-23
This section supersedes the earlier partial-code status above, not its audit history.

The shared final gate now keeps independently certified pass/warning outputs when a
sibling is manual, failed or lacks a required face receipt. Incomplete package receipts
and contradictory duplicate output rows remain non-certifying. E34 keeps opaque output
IDs, recommended IDs and quality/evidence axes while excluding raw provider evidence.
Project certification and both candidate/asset summaries require the exact eligible
output ID; sharing an asset ID cannot disclose another withheld candidate.

The merger no longer clears certified siblings merely because one ready output lacks
pixel certification. Metadata preflight and evidence-only failures never establish a
visual-quality failure. Real candidates use planning-only structure diagnostics, not
mock acceptance or metadata-driven renderer retries. Public quality scores come only
from real inspection score cards once the canonical delivery gate applies.

Human scope is transported from frozen typed Brain entities/attributes through the
activation planner, shared Human Realism contribution and frozen review contract.
Product-only scopes do not activate Human Realism. Hand/limb-only scopes retain material,
anatomy and contact review without a face/identity/age obligation. Explicit portraits
remain subject to face certification. Existing exact output/reference bindings and
browser/provider self-exemption protections remain enforced.

Brand tone/palette facts are retained in the shadow compilation as metadata and passed
to both Brain planning and final signing. Signing reuses the planning-stage brand facts;
it does not reload changed defaults or append local prose to an already signed prompt.
No-pixel Brain failures now explicitly expose brain_timeout/provider_unavailable categories
and quality_assessment=not_assessed, quality_failure=false. Existing bounded transport,
request acceptance, phase and elapsed-time evidence remain unchanged.
